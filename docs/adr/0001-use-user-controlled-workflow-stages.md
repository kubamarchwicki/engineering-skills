# Use user-controlled workflow stages

Engineering Skills uses two manually selected Tracks—a Light Track for focused changes and a Heavy Track for multi-stage work—and treats every transition as a Gear Shift explicitly initiated by the user. Skills may recommend the exact next Skill but never auto-chain or merge; this trades maximum autonomous throughput for predictable control, makes every Stage independently inspectable, and leaves merging, sanity testing, and cleanup with the user.
